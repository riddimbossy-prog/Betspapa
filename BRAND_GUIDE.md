# BetsPapa Brand Guide

## Core identity

**Brand:** BetsPapa  
**Tagline:** Papa Knows the Game  
**Mascot:** 3D caricature — red trucker hat, clear glasses, mustache, red shearling jacket  
**Personality:** Experienced, sharp, colourful, trustworthy.
